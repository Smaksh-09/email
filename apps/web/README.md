# Outbox dashboard

The frontend for composing email campaigns, scheduling delivery, and inspecting message history.

Uses Next.js App Router, React, TypeScript, and Tailwind CSS. It connects to the Express API in `apps/api`.

Follow the [repository setup guide](../../README.md) to configure authentication, start the API and infrastructure, and run both applications.

From the repository root, start the dashboard with `npm run dev:web`. The local dashboard runs at http://localhost:3000.
